# §7.7 UI 图像模式 — 设计规格（修订版）

> 基于原型迭代确定的视觉小说界面设计。文本模式界面零改动。

## §2 布局与层级

### 2.1 z-index 层级

| 层级 | 元素 | z-index |
|------|------|---------|
| 0 | `.vn-bg` 背景图（cover） | 0 |
| 1 | `.vn-sprites` 立绘（居中，bottom:0，max-height:70vh） | 1 |
| 2 | `.vn-dialog` 对话框（底部固定高度） | 5 |
| 3 | `.vn-choices-overlay` 选项（全屏居中） | 20 |
| 4 | `.vn-settings-overlay` / `.vn-backlog-overlay` | 30 |

### 2.2 对话框

- **背景**：`linear-gradient(to top, rgba(10,10,26,0.80) 0%, rgba(10,10,26,0.35) 70%, transparent 100%)`
- **高度**：固定 `var(--vn-dialog-height)`（防止打字机抖动），默认 14rem
- **文字列宽**：`max-width: 760px`，左对齐
- **底部间距**：`padding-bottom: 3rem`

### 2.3 名字标签

`segment` 事件带 `char` 字段时显示。绿色左边框标签，位于对话框文字上方：
- `border-left: 2px solid var(--text-accent)`
- `background: rgba(78,204,163,0.10)`

### 2.4 打字机效果

- 逐字显示，`setTimeout` 驱动
- 首次点击：立即显示全文（跳过打字）
- 全文显示后：出现 ▼ 指示器
- 再次点击：推进到下一段
- 速度由 `--vn-char-delay` 控制（JS 中 `SPEEDS` 常量）

### 2.5 选项

- 全屏半透明遮罩 + 居中垂直排列
- **无外框**：选项面板无 border/background/box-shadow
- 按钮：纯黑底 `rgba(0,0,0,0.7)`，字号与正文同步（`var(--vn-font-size)`）
- 间距：`var(--vn-choice-gap)`（1.4rem）
- 置灰选项：`opacity: 0.55`，附带条件原因文字

### 2.6 回看（Backlog）

- 半透明全屏遮罩
- 滚动列表，宽度与对话框一致（760px）
- 名字 + 文本逐条展示
- Esc 或 ✕ 关闭

### 2.7 沉浸模式

- 隐藏顶栏 + 对话框，仅保留背景+立绘
- 点击画面退出沉浸模式
- 顶栏 `opacity: 0; pointer-events: none` 过渡

## §3 CSS 自定义属性（可调参数）

所有可调参数集中定义在 `graph.css` 的 `:root` 中：

```css
:root {
  /* 由设置面板动态修改 */
  --vn-font-size: 1.35rem;      /* 正文 + 选项同步 */
  /* 静态常量 */
  --vn-dialog-height: 14rem;    /* 对话框固定高度 */
  --vn-choice-gap: 1.4rem;      /* 选项按钮间距 */
  --vn-text-max-width: 760px;   /* 文字列宽 */
  --vn-sprite-max-h: 70vh;      /* 立绘最大高度 */
  --vn-sprite-max-w: 45vw;      /* 立绘最大宽度 */
}
```

## §4 JavaScript 常量

所有可调参数集中在 `graph-renderer.js` 顶部：

```javascript
const SPEEDS       = { slow: 25, normal: 15, fast: 8 };        // ms/char
const AUTO_DELAYS  = { short: 1.0, normal: 2.0, long: 3.5 };   // seconds
const FONT_SIZES   = { small: "1.15rem", medium: "1.35rem", large: "1.55rem" };
```

设置面板通过修改 `:root` CSS 变量或更新模块变量实现联动（正文+选项字体同步）。

## §5 组件接口

### 5.1 GraphRenderer

```javascript
const GraphRenderer = {
  init(container, gameMode)    // 构建 VN DOM 结构
  /* 图层 */
  setBackground(url)           // 设置背景（fade-in）
  setSprite(url)               // 设置/替换立绘
  clearSprite()                // 移除立绘
  /* 文本 */
  showSegment(text, charName)  // 打字机显示文本 + 名字标签
  skipTypewriter()             // 立即显示全文
  /* 选项 */
  showChoices(choices, onSelect) // 显示选项，回调返回 key
  clearChoices()               // 移除选项
  /* 覆盖层 */
  showBacklog(history)         // 显示回看
  hideBacklog()
  showSettings(getSpeed, setSpeed, getFont, setFont, getAuto, setAuto)
  hideSettings()
  /* 模式 */
  setAutoMode(bool)
  setImmersive(bool)
  /* 生命周期 */
  destroy()                    // 清理 DOM
}
```

## §6 事件处理

### 6.1 显示循环差异

文本模式使用队列缓冲 + `_displayTick` 逐条消费。**图像模式不使用队列**——打字机本身即是节奏控制：

```
文本模式: SSE → _eventQueue.push() → _displayTick() → Display.appendSegment()
图像模式: SSE → GraphRenderer.showSegment() → 打字机 → 等待点击/自动延迟 → advance
```

### 6.2 SSE 事件处理表

| SSE 事件 | 文本模式 (Display) | 图像模式 (GraphRenderer) |
|----------|-------------------|-------------------------|
| `story_begin` | silent | silent |
| `story_end` | silent | silent |
| `segment` | `Display.appendSegment(text)` | `GraphRenderer.showSegment(text, char)` → 打字机 |
| `segment` + `assets.background_img` | 忽略 | `GraphRenderer.setBackground(url)` |
| `segment` + `assets.char_portrait` | 忽略 | `GraphRenderer.setSprite(url)` |
| `scene` + `assets.background_img` | 忽略 | `GraphRenderer.setBackground(url)` |
| `bridge` | push to queue | 同文本模式（等待下一轮） |
| `options` | defer to queue-end → `_handleOptions` | 立即展示 → `GraphRenderer.showChoices()` |
| `state` | `GameState.stateVars = data.vars` | 同文本模式 |
| `save` | toast | 同文本模式 |
| `error` | modal | 同文本模式 |
| `ending` | set flag | 同文本模式 |
| `done` | update counters | 同文本模式 |

### 6.3 选项处理流程

```
图像模式收到 options 事件:
  1. GraphRenderer.showChoices(data.choices, callback)
  2. 用户点击选项 → callback(key)
  3. game.js: Display.appendChoiceText(label)  // 复用绿色文本
  4. game.js: SSEClient.sendChoice(gameId, key)
  5. 服务端 gen.send(key) → 继续产出事件
  6. 下一个 segment → 打字机显示
```

### 6.4 图片 URL 构造

```javascript
function assetUrl(assetType, assetId) {
  return `/media/${assetType}/${assetId}.png`;
}
// 例: assetUrl("char_portrait", "stub_default_portrait")
//   → "/media/char_portrait/stub_default_portrait.png"
```

## §7 端到端流程

### 7.1 完整用户流程

```
┌─ 设置 game_mode = "graph" ──────────────────────────────────┐
│  UserConfig.save() → config.json                            │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ 主菜单 → "New Game" → #co-create ──────────────────────────┐
│  自由共创 Q&A（不变）                                        │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ 用户点击 "Generate" ───────────────────────────────────────┐
│  co-create.js: 显示过渡屏 ("Preparing your world...")       │
│  POST /api/co-create/generate                               │
│    服务端:                                                   │
│      1. GameSession.start_game(result, game_mode="graph")   │
│      2. game_mode == "graph":                               │
│         a. _init_stub_assets(media_dir) — 幂等初始化 media/ │
│         b. 为 story_config 中每个 location/character        │
│            在 _asset_roster.json 中创建占位条目 (target=null)│
│      3. 保存 _init.json (含 story_config)                   │
│      4. 返回 { game_id, game_mode: "graph", story_config }  │
│  co-create.js: GameState.gameMode = "graph"                 │
│  navigate("game-preview")                                   │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ 游戏预览页 #game-preview ──────────────────────────────────┐
│  展示故事标题 + 设定                                        │
│  用户点击 "Begin Adventure"                                 │
│  router.js → #game/{id}                                     │
│  renderGame(gameId):                                        │
│    gameMode = GameState.gameMode  // "graph"                │
│    GameView.render(app, gameId, title, "graph")             │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ GameView.render() ─────────────────────────────────────────┐
│  if (gameMode === "graph"):                                 │
│    _buildGraphDOM()  → VN DOM 结构                          │
│    GraphRenderer.init(container)                            │
│  else:                                                      │
│    _buildDOM()       → text DOM 结构                        │
│    Display.init(container)                                  │
│  POST /api/game/{id}/start → Round 1                       │
│  _connectSSE()                                              │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ SSE 叙事循环 (Round 1 .. N) ──────────────────────────────┐
│  graph 模式: 打字机驱动，直接渲染                           │
│  text 模式:  队列缓冲，逐条显示                             │
│  ... 多轮叙事 + 选项 ...                                   │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ 结局 (ending → done) ─────────────────────────────────────┐
│  服务端: 生成冒险日志（不变）                               │
│  UI:                                                        │
│    graph 模式: 对话框内显示绿色按钮                         │
│      "The story has ended. View adventure log."             │
│      点击 → _stopDisplayLoop() → Router.navigate(logHash)  │
│    text 模式: 同现有 _showEndChoice()                      │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─ 冒险日志页 #adventure-log/{id} ───────────────────────────┐
│  AdventureLogView.render() — 与文本模式完全相同             │
│  滚动阅读，Export 按钮（预留）                              │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 存档读取流程

```
主菜单 → "Continue" 或 "Load Save"
  → POST /api/saves/{id}/start/{file}
  → GameSession._load_from_data() 重建 GameLoop
  → 模式来自 UserConfig.game_mode（非存档文件）
  → game-preview → "Begin Adventure" → 同 §7.1 流程
```

存档本身不记录模式。图像模式的存档在文本模式下打开 → 文本模式 UI 展示（忽略 assets 字段）。反之亦然。

### 7.3 模式传递链

```
server.py                          JS
─────────                          ──
config.json ──cfg.game_mode──→ (server decisions)
co-create/generate ──game_mode──→ GameState.gameMode
game/{id}/start    ──game_mode──→ (verify)
                                   ↓
                                   router.js renderGame()
                                   ↓
                                   GameView.render(container, gameId, title, gameMode)
                                   ↓
                                   gameMode === "graph" → GraphRenderer
                                   gameMode === "text"  → Display
```

### 7.4 服务端素材预构建（stub）

`GameSession.start_game()` 在 `game_mode == "graph"` 时：

```
1. _init_stub_assets(cfg.media_dir):
    若 media/ 不存在 → 创建目录 + 复制 stub 图片 + 写 _asset_lib.json
    若已存在 → 跳过

2. 初始化 GameAssetRoster:
    对 story_config 中每个 location:
      roster.add(AssetType.BACKGROUND, local_name, local_description, target=None)
    对 story_config 中每个 character:
      roster.add(AssetType.CHAR_PORTRAIT, local_name, local_description, target=None)
    保存 _asset_roster.json

3. 保存 _init.json（含 story_config + progress）
```

> 当前 stub 阶段不真正调用 AI 生成。7.8c（共创预构建）将替换此逻辑。
