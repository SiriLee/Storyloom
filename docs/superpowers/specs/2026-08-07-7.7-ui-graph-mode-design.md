# §7.7 UI 图像模式 — 设计规格（修订版）

> 基于原型迭代确定的视觉小说界面设计。文本模式界面零改动。

## §2 布局与层级

### 2.1 z-index 层级

| 层级 | 元素 | z-index |
|------|------|---------|
| 0 | `.vn-bg` 背景图（cover） | 0 |
| 1 | `.vn-sprites` 立绘（居中，bottom:0，max-height:70vh） | 1 |
| 2 | `.vn-dialog` 对话框（底部固定高度） | 5 |
| 3 | `.vn-choices-overlay` 选项（全屏居中） | 20 |
| 4 | `.vn-settings-overlay` / `.vn-backlog-overlay` | 30 |

### 2.2 对话框

- **背景**：`linear-gradient(to top, rgba(10,10,26,0.80) 0%, rgba(10,10,26,0.35) 70%, transparent 100%)`
- **高度**：固定 `var(--vn-dialog-height)`（防止打字机抖动），默认 14rem
- **文字列宽**：`max-width: 760px`，左对齐
- **底部间距**：`padding-bottom: 3rem`

### 2.3 名字标签

`segment` 事件带 `char` 字段时显示。绿色左边框标签，位于对话框文字上方：
- `border-left: 2px solid var(--text-accent)`
- `background: rgba(78,204,163,0.10)`

### 2.4 打字机效果

- 逐字显示，`setTimeout` 驱动
- 首次点击：立即显示全文（跳过打字）
- 全文显示后：出现 ▼ 指示器
- 再次点击：推进到下一段
- 速度由 `--vn-char-delay` 控制（JS 中 `SPEEDS` 常量）

### 2.5 选项

- 全屏半透明遮罩 + 居中垂直排列
- **无外框**：选项面板无 border/background/box-shadow
- 按钮：纯黑底 `rgba(0,0,0,0.7)`，字号与正文同步（`var(--vn-font-size)`）
- 间距：`var(--vn-choice-gap)`（1.4rem）
- 置灰选项：`opacity: 0.55`，附带条件原因文字

### 2.6 回看（Backlog）

- 半透明全屏遮罩
- 滚动列表，宽度与对话框一致（760px）
- 名字 + 文本逐条展示
- Esc 或 ✕ 关闭

### 2.7 沉浸模式

- 隐藏顶栏 + 对话框，仅保留背景+立绘
- 点击画面退出沉浸模式
- 顶栏 `opacity: 0; pointer-events: none` 过渡

## §3 CSS 自定义属性（可调参数）

所有可调参数集中定义在 `graph.css` 的 `:root` 中：

```css
:root {
  /* 由设置面板动态修改 */
  --vn-font-size: 1.35rem;      /* 正文 + 选项同步 */
  /* 静态常量 */
  --vn-dialog-height: 14rem;    /* 对话框固定高度 */
  --vn-choice-gap: 1.4rem;      /* 选项按钮间距 */
  --vn-text-max-width: 760px;   /* 文字列宽 */
  --vn-sprite-max-h: 70vh;      /* 立绘最大高度 */
  --vn-sprite-max-w: 45vw;      /* 立绘最大宽度 */
}
```

## §4 JavaScript 常量

所有可调参数集中在 `graph-renderer.js` 顶部：

```javascript
const SPEEDS       = { slow: 25, normal: 15, fast: 8 };        // ms/char
const AUTO_DELAYS  = { short: 1.0, normal: 2.0, long: 3.5 };   // seconds
const FONT_SIZES   = { small: "1.15rem", medium: "1.35rem", large: "1.55rem" };
```

设置面板通过修改 `:root` CSS 变量或更新模块变量实现联动（正文+选项字体同步）。

## §5 组件接口

### 5.1 GraphRenderer

```javascript
const GraphRenderer = {
  init(container, gameMode)    // 构建 VN DOM 结构
  /* 图层 */
  setBackground(url)           // 设置背景（fade-in）
  setSprite(url)               // 设置/替换立绘
  clearSprite()                // 移除立绘
  /* 文本 */
  showSegment(text, charName)  // 打字机显示文本 + 名字标签
  skipTypewriter()             // 立即显示全文
  /* 选项 */
  showChoices(choices, onSelect) // 显示选项，回调返回 key
  clearChoices()               // 移除选项
  /* 覆盖层 */
  showBacklog(history)         // 显示回看
  hideBacklog()
  showSettings(getSpeed, setSpeed, getFont, setFont, getAuto, setAuto)
  hideSettings()
  /* 模式 */
  setAutoMode(bool)
  setImmersive(bool)
  /* 生命周期 */
  destroy()                    // 清理 DOM
}
```

### 5.2 DOM 结构（由 `init()` 创建）

```html
<div class="vn-scene">

  <div class="vn-sprites"></div>

```

## §6 事件处理

### 6.1 现有事件扩展

| SSE 事件 | graph 模式行为 |
|----------|---------------|
| `segment` | `GraphRenderer.showSegment(data.text, data.char)` |
| `segment` + `assets.background_img` | `GraphRenderer.setBackground(url)` |
| `segment` + `assets.char_portrait` | `GraphRenderer.setSprite(url)` |
| `scene` | `GraphRenderer.setBackground(url)` (如有 assets) |
| `options` | `GraphRenderer.showChoices(data.choices, sendChoice)` |
| `bridge` / `state` / `error` / `ending` / `done` | 同文本模式 |

### 6.2 新 SSE 事件（无需新增）

当前 `segment` 事件已包含 `char` 和 `assets` 字段（EventDispatcher.dispatch 产出）。UI 层直接读取即可。

## §7 模式传递

- `POST /api/co-create/generate` 响应增加 `game_mode`
- `POST /api/game/{id}/start` 响应增加 `game_mode`
- Router → `GameView.render(container, gameId, title, gameMode)`
- `gameMode === "graph"` 时初始化 GraphRenderer，否则使用 Display（文本模式）
