## 三、产品体系与技术方案

<!-- 对应维度：创新维度（主战场）。 -->

### 3.1 产品形态
- **双模式**：文本模式（纯文字冒险）+ 图模式（视觉小说：立绘、背景、分支）。
- **共创流程**：AI 访谈用户想法 → 生成世界观/角色/剧情大纲/变量体系 → 预构建素材 → 进入游戏。
- **游戏体验**：桥接无感生成、双层分支（段内选项 + 大纲级路线分叉）、实时素材呈现、存档读档。

### 3.2 技术架构
| 模块 | 作用 |
|---|---|
| 流式解析管线 | StreamParser → StateManager → EventDispatcher，逐行解析不缓冲 |
| 桥接预取 | 段落中途发起下一轮 API 调用，隐藏时延 |
| 状态校验 | LLM 只建议写，引擎类型校验后才应用，拒绝回写 |
| 双层分支 | 段内 choice + 大纲 route |
| 素材管线 | O(1) 目录匹配 → LLM 匹配 → AI 生成，异步非阻塞 |
| 上下文管理 | 滑动窗口 + Round 1 锚定 + checkpoint 压缩（约 50K token） |
| 共创 | AI 访谈 → story_config → 大纲 |
| Web UI | FastAPI + SSE + 原生 JS SPA |

<!-- 代码对应：parser/stream_parser.py、core/game_loop.py、core/state_manager.py、
     assets/、tasks/、core/context_manager.py、core/co_create.py、web/ -->

### 3.3 工程质量
- 开源（MIT）、版本 v2.1.0。
- 1,100+ 单元测试全绿；mock 测试不依赖真实 API。
- 打包：PyInstaller 独立二进制 + pip wheel + 系统素材包（约 267MB）。
- i18n：英 / 简体 / 繁体（gettext）。

## 四、创新点与核心壁垒

<!-- 对应维度：创新维度（评委定级关键）。 -->

| # | 创新点 | 一句话论据 |
|---|---|---|
| 1 | 第一性原理驱动架构 | 从「生成有时延 + 交互含不确定」两条公理推导出桥接机制 |
| 2 | 桥接机制（隐藏等待） | 缓冲内容与下一轮生成重叠，用户感知不到生成时延 |
| 3 | 引擎级状态校验 | LLM 只建议写，程序类型校验后才应用，解决剧情失控 |
| 4 | 素材管线 | 目录 O(1) 匹配 → LLM 兜底 → AI 生成，素材与剧情异步解耦 |
| 5 | LLM 自定义变量体系 | 放弃硬编码模板，共创阶段由 LLM 生成变量，支撑任意故事 |
